# ⚡ TechPeek — Instant Web Tech Stack Profiler

> **A fast, lightweight, and open alternative to Wappalyzer for Microsoft Edge & Google Chrome.**

**TechPeek** is a browser extension that instantly reveals the complete technology stack behind any website you visit with a single click. It detects JavaScript frameworks, web servers, cloud hosting providers (PaaS), UI libraries, analytics, tag managers, and cookie compliance tools.

---

## 🚀 Key Features

* **⚡ Instant In-Browser Detection**: Analyzes live DOM, global JavaScript objects, meta tags, and headers in real-time.
* **📦 Categorized Technology Breakdown**:
  * **JavaScript Frameworks & Libraries**: Next.js, React, Vue.js, Nuxt.js, Angular, Svelte, Gatsby, jQuery, Lodash, Axios, Alpine.js, HTMX.
  * **Animation & UI Tools**: Framer Motion, Radix UI, Tailwind CSS, Bootstrap, LottieFiles.
  * **PaaS & Hosting Infrastructure**: Vercel, Amazon Web Services (AWS), Netlify, Cloudflare, GitHub Pages, Heroku, Google Cloud.
  * **Web Servers**: Next.js Server, Nginx, Apache Server.
  * **Analytics & Customer Data Platforms (CDP)**: Google Analytics, PostHog, Segment, LinkedIn Insight Tag, Hotjar.
  * **Tag Managers**: Google Tag Manager (GTM).
  * **Cookie Compliance**: Cookiebot, Cookie Control (Civic).
  * **Performance & SEO**: Priority Hints (`fetchpriority`), Open Graph meta tags.
* **🔒 100% Privacy Focused**: Runs completely locally inside your browser. No third-party data tracking or external logging.
* **🎯 Zero Setup Required**: Ready to use in any Chromium browser (Edge, Chrome, Brave, Opera).

## 📥 How to Install in Microsoft Edge

Follow these quick steps to load TechPeek into Microsoft Edge:

### Step 1: Open Edge Extensions
1. Open **Microsoft Edge**.
2. Type `edge://extensions/` into the address bar and press **Enter**.

### Step 2: Enable Developer Mode
1. In the left-hand sidebar (or bottom-left), toggle **Developer mode** to **ON**.

### Step 3: Load the Unpacked Extension
1. Click the **"Load unpacked"** button at the top of the Extensions page.
2. Select the extension directory:
   ```text
   C:\Users\Nihal\Downloads\own_shity\chrome-detector-extension
   ```
3. Click **"Select Folder"**.

### Step 4: Pin TechPeek to Toolbar
1. Click the **puzzle piece icon** (Extensions) in the top-right toolbar of Edge.
2. Click the **Eye / Pin icon** next to **TechPeek** to keep it accessible on your toolbar.

---

## 🌐 How to Install in Google Chrome / Brave

1. Open **Google Chrome** (or Brave) and go to `chrome://extensions/`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** in the top-left corner.
4. Select the `chrome-detector-extension` folder.
5. Pin **TechPeek** to your extensions bar.

---

## 💡 How to Use

1. Navigate to any website you want to inspect (e.g., `https://github.com`, `https://vercel.com`, `https://linear.app`).
2. Click the **TechPeek icon** on your browser toolbar.
3. The popup will open and categorize all detected technologies, frameworks, and versions.
4. Click **Rescan** anytime to refresh the analysis for dynamic or single-page applications (SPAs).
